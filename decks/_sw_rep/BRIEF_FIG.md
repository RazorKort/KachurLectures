# Задача: картинки-схемы из pptx 2.2 → перерисовка в SVG/вёрстку

Сначала прочитай `_sw_rep/BRIEF.md` (механизм, инструменты) и эталон `_sw_rep/snap.py`.

Сейчас в деке есть слайды, где рисунки из pptx (схемы, топологии, выводы CLI, скриншоты CLI) вставлены
картинкой на белой подложке (`_sw_fig.py`, картинки `_sw_assets/fig_<имя>.webp`). Это плохо: надо **перерисовать**.

Для каждой своей картинки `fig_<имя>` создай `_sw_rep/fig_<имя>.py` (`W, H` = размер `_sw_assets/fig_<имя>.webp`,
`TOP = 0`, `HTML`). Как только файл есть, слайд автоматически покажет вёрстку вместо картинки.

## Как рисовать
- **Структура 1:1 с картинкой** (те же элементы, подписи дословно, те же позиции/пропорции), но **в стиле деки**:
  тёмная неоновая палитра (фон прозрачный — под вёрсткой и так тёмно-синяя подложка), линии/рамки неоновые
  (#2ad4ff, #9b6bff, #e05cff, #9dfc5a, #ffc53d, #ff4d5e), текст светлый. Цветовая логика оригинала сохраняется
  (красный VLAN остаётся красным, оранжевые ARP-стрелки — оранжевыми, зелёные «Вход/Выход» — зелёными).
- **Схемы и топологии — inline SVG** (коммутаторы, ПК, маршрутизаторы, облако, стрелки, конверты — рисуй векторно:
  простые узнаваемые неоновые иконки; можно один раз определить `<symbol>` в своём SVG, id с префиксом своего имени).
- **Выводы CLI/терминал** — HTML: `<pre>` моноширинным JetBrains Mono, тёмная консоль, команды подсвечены (#9dfc5a),
  текст дословно, выравнивание колонок как в оригинале. Подписи «Рисунок …» — курсивом снизу, как в оригинале.
- **Анимация** (`step` + CSS keyframes): стрелки/линии прорисовываются (stroke-dashoffset), пакеты/конверты летят
  по связям, в CLI строки печатаются построчно, метки VLAN появляются. 3–8 шагов.
- Кропы НЕ нужны (это перерисовка), кроме случаев, которые нельзя нарисовать.
- Префикс CSS-классов и id — `<имя>-` (например `.s40-…`), никаких общих имён вроде `.big`, `.pan`, `.t`, `.c`.
