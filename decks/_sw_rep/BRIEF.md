Дека `D:/Преза лекций/decks/kommutaciya.html` (сборка `_sw_build.py`). Сейчас неоновые инфографики вставлены
плоской картинкой (`pic("имя")` → `_sw_assets/<имя>.webp`). Нужно для каждой своей инфографики сделать
**вёрстку 1:1**: файл `_sw_rep/<имя>.py` — тогда `pic()` автоматически покажет вёрстку вместо картинки.

**ЭТАЛОН — `_sw_rep/snap.py`. Прочитай его целиком и делай так же** (по качеству и приёмам).

## Формат файла `_sw_rep/<имя>.py`
- `W, H = 1672, 941` — холст = пиксели оригинала; `TOP = N` — сколько пикселей сверху срезать (полоса с большим
  заголовком/подзаголовком оригинала: на слайде деки заголовок уже есть в `head()`). Подбери по оригиналу (обычно 110–160).
- `HTML` — абсолютная вёрстка в координатах оригинала (left/top/width в px как на картинке 1672×941).
  Свой `<style>` внутри HTML — классы называй с префиксом имени инфографики (`.hub-box`), чтобы не конфликтовать с другими.
- Шрифты: Oswald (заголовки/подписи плашек), Golos Text (текст), JetBrains Mono (адреса/команды). Цвета неона: #2ad4ff, #9b6bff, #e05cff, #9dfc5a, #ffc53d, #ff4d5e.
- Плашки, рамки, стрелки, таблицы, текст — **вёрсткой** (div/svg), тексты дословно с картинки.
- Иконки, объёмные рисунки (коммутаторы, ПК, серверы, кабели, чипы) — **вырезка из оригинала**:
  `python _sw_rep/_crop.py <имя> x0 y0 x1 y1 <имя>_что.png` (пиксели оригинала 1672×941) → в HTML `img("rep/<имя>_что.png", "left:..px;top:..px;width:..px", "ab")`
  (`from _sw_lib import img`, см. эталон). Файлы кропов — только с префиксом своей инфографики.
- Анимация: класс `step` на блоках, появляются по порядку DOM (3–9 шагов, по смыслу: ряд, панель, стрелка, пример).
  Не вешай свой `transform` на элемент с классом `step` (он анимирует transform) — оберни.
  Задержка внутри шага: `transition-delay`. Движение (пакет летит по стрелке, мигание порта) — CSS @keyframes, где по смыслу уместно.
