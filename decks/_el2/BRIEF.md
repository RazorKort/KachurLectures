# Задача агента: слайды деки = оригинал pptx «как на фото»

Дека `D:/Преза лекций/decks/eltex-devices-2.html` (собирается `_el2_build.py` из модулей `_el2/s*.py`).
Каждый слайд — HTML-воспроизведение картинки-слайда из pptx. Оригиналы: `_el2ref/sNN.jpg` (NN = номер слайда pptx, ~1672x941).
Соответствие ref → номер pptx: `_el2/pptxmap.py`. Сначала прочитай `_el2/KIT.md` (классы, вёрстка 1920x1080, анимация `data-s`).

Цель: слайд деки должен выглядеть **максимально как оригинал**: та же композиция, те же позиции и размеры блоков,
те же заголовки и тексты (дословно с картинки), те же иконки, иллюстрации, фото устройств, схемы, цвета акцентов
(оранжевые/зелёные/красные плашки там, где они в оригинале). Пересчёт координат: x_деки = x_оригинала * 1920/W, y = y * 1080/H.

## Инструменты
- Сверка: `PYTHONIOENCODING=utf-8 python _el2/compare.py p044 p059` → `_el2cmp/p044.jpg`: сверху оригинал, снизу дека (все шаги показаны).
  Смотри картинку (Read) и правь, пока не будет похоже. Минимум 2–3 итерации на слайд.
- Вырезка из оригинала: `python _el2/crop.py 70 x0 y0 x1 y1 p070_ico_wifi.png --white` (доли 0..1; `.png --white` —
  светлый фон становится прозрачным, для иконок/устройств на карточках; `.jpg` — для крупных сцен, схем, скриншотов).
  Файл ложится в `_el2assets/`, в HTML: `<img class="ab" src="assets/имя" style="left:..px;top:..px;width:..px">`.
  Имена с префиксом номера pptx: `p070_...` — уникальные.
- **Иконки, объёмные значки, фото устройств, иллюстрации, сцены, скриншоты веб-интерфейса — вырезай из оригинала**,
  а не рисуй линейные `ico()`: так получаются «как на фото». Если в `_el2assets/dev/*.webp` есть официальное фото Eltex
  той же модели в лучшем качестве и с тем же ракурсом — можно его. Пиксельные/рваные вырезки недопустимы — перевырезай.
- Текст оставляй живым HTML (не вырезай текст картинкой), шрифты/классы из KIT.

## Правила
- Правишь ТОЛЬКО свои файлы (перечислены в задании). `_el2_lib.py`, `_el2_build.py`, `order.py`, `pptxmap.py`, чужие модули — не трогать.
  `eltex-devices-2.html` не собирать (compare.py собирает во временный файл).
- Анимация: сохраняй/добавь пошаговое появление `data-s` (3–8 шагов, по смыслу: блок/пункт/стрелка), заголовок виден сразу.
- При сборке мелкий шрифт поднимается (`bump` в `_el2_build.py`: <MINPX → MINPX, <26px → +1.5px) — проверяй по сверке, что текст не вылезает из карточек и не наезжает.
- Ничего не выдумывать: только то, что на оригинале.
- В конце: прогон compare.py по всем своим слайдам, финальный просмотр каждого, `python -c "import ast;ast.parse(open(f,encoding='utf-8').read())"` для своих файлов.
- Отчёт (кратко, по-русски): какие слайды переделаны, что осталось непохожим.

## ДОПОЛНЕНИЕ (приоритет выше всего выше)
- **Оборудование (маршрутизаторы, коммутаторы, точки доступа, контроллеры, базовые станции) — только официальные фото с сайта Eltex** (eltex-co.ru), не вырезки из оригинала.
  Сначала смотри `_el2assets/dev/` (уже скачанные). Нет нужной модели/ракурса (задняя панель и т.п.) — скачай с eltex-co.ru (страница модели,
  картинка товара наибольшего размера) в `_el2assets/dev/<модель>.webp|jpg|png`, проверь, что это та же модель. Белый фон — допустим/убери до прозрачного.
  Если на сайте такого ракурса нет вообще — тогда чистая вырезка из оригинала.
- **Разъёмы, кабели, модули, трансиверы (RJ-45, SFP, консольный кабель, USB, кнопка F, вентиляторы, клеммы, память) — тоже фото**, не линейные иконки:
  вырезка из оригинала или реальное фото (сайт Eltex).
- Иконки/значки — как и раньше, вырезка из оригинала.
- Срок: презентация показывается СЕГОДНЯ. Делай быстро: сначала все слайды до «прилично и похоже», потом шлифовка.
